# Implementation Guide
## Student Information System Rollout — Attendance Module

**Audience:** School site administrators, attendance clerks
**Rollout Phase:** Phase 2 of 4 (Attendance and Enrollment modules)

---

### 1. Before Rollout Day

1. Confirm your school's site administrator account is active in the new system (provisioned automatically from the legacy system 2 weeks prior to rollout).
2. Complete the required 90-minute attendance-clerk training session, scheduled the week before your site's rollout date.
3. Print the quick-reference card distributed at training and keep it at the attendance desk during the first two weeks of live use.

### 2. Rollout Day Sequence

1. **7:00 AM** — Legacy attendance system switches to read-only mode. Do not attempt to take attendance in the legacy system after this point.
2. **7:15 AM** — New system becomes available for attendance entry. Site administrators verify their roster loaded correctly before first period begins.
3. **First period** — Attendance clerks take attendance using the new system for the first time, with a support hotline staffed for immediate troubleshooting.
4. **End of day** — Site administrator runs the daily attendance reconciliation report and confirms it matches expected enrollment counts within normal tolerance.

### 3. What's Different From the Legacy System

- Attendance codes have been consolidated from 14 codes down to 8, with a mapping table provided at training — if you're looking for a code you used before and don't see it, check the mapping table before calling the support hotline.
- Same-day attendance corrections no longer require administrator override; any attendance clerk can correct a same-day entry within the first 24 hours.
- The new system flags chronic absenteeism automatically based on state-defined thresholds, which previously required a manual monthly report.

### 4. Common Rollout-Day Issues

**"A student is missing from my roster."**
Check the enrollment sync status indicator on the roster screen first — a small percentage of enrollment records complete their sync in the hour after go-live. If the student is still missing after 9:00 AM, contact the support hotline with the student ID.

**"I can't find the excused-absence documentation upload option."**
This has moved from the attendance screen to the student's profile page, under the Documentation tab, as part of the module consolidation.

### 5. Support

A dedicated support hotline is staffed from 6:30 AM to 4:00 PM on rollout day and the two following school days, after which standard help desk support applies.

---
*This guide has been generalized from production implementation documentation for a multi-year student information system migration. System names, timelines, and specific configuration details have been altered.*
