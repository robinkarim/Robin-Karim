# Product and Operating Specification
## Wellhead Pressure Relief Valve Assembly, Model PRV-200 Series

---

### 1. Product Overview

The PRV-200 series pressure relief valve assembly protects wellhead equipment from overpressure events by opening at a pre-set threshold to safely vent excess pressure, then reseating automatically once pressure returns to normal operating range.

### 2. Specifications

| Parameter | Value |
|---|---|
| Set pressure range | 500–3,000 psi (field-adjustable within range) |
| Operating temperature range | -20°F to 250°F |
| Body material | Forged steel, corrosion-resistant coating |
| Reseat pressure | 90–95% of set pressure |
| Inlet/outlet connection | Flanged, per applicable ANSI class rating |
| Certification | Factory-tested and tagged prior to shipment |

### 3. Installation

1. Confirm the valve's certified set pressure matches the system's required relief setting before installation — do not install a valve with an unverified or mismatched set pressure.
2. Install in the vertical orientation specified in the mounting diagram; horizontal mounting is not supported for this model and voids the factory pressure certification.
3. Torque flange bolts to the manufacturer-specified sequence and value, not a single uniform torque applied all at once.
4. Complete a functional test at commissioning per Section 5 before the system is placed into service.

### 4. Operation

Under normal operation, the valve remains closed and requires no operator action. When system pressure reaches the set pressure, the valve opens automatically to vent excess pressure, then reseats once pressure drops below the reseat threshold. No manual reset is required for normal relief events.

### 5. Commissioning and Periodic Testing

1. At commissioning, and at each scheduled maintenance interval thereafter, verify the valve opens at its certified set pressure using the approved test bench procedure — field pressure testing on a live system is not permitted for this model.
2. Document the test result, including actual opening pressure observed, in the equipment maintenance log.
3. If the observed opening pressure falls outside ±3% of the certified set pressure, the valve must be removed from service and either recertified or replaced — it may not be field-adjusted and returned to service without recertification.

### 6. Maintenance Intervals

Standard maintenance interval is every 12 months or per the site's regulatory inspection schedule, whichever is more frequent. Valves in high-cycle service (frequent relief events) may require more frequent inspection per the site EHS engineer's determination.
