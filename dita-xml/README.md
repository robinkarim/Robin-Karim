# DITA XML Writing Samples

Samples from structured authoring work in DITA (Darwin Information Typing Architecture), built and maintained in Arbortext Editor and Adobe FrameMaker.

## What's in here

- **Task and concept topics** — the two core DITA topic types, shown here as paired samples so you can see how I split procedural steps (task) from background and explanatory content (concept) rather than blending them into one long document
- **Reference topics** — structured lookup content (specs, parameter tables) built to the same modular standard
- **Reuse and maps** — where applicable, notes on how topics were assembled into ditamaps for multi-output publishing (PDF, HTML, help systems)

## Background

This work was produced primarily during a ServiceNow and Azure cloud migration program, and separately for an IT infrastructure build-document repository, both of which relied on DITA's topic-based structure to keep content modular and reusable across releases and output formats. Deliverables were managed in Confluence and Jira within an Agile/Scrum framework. Client-identifying details have been redacted or generalized.

Note: an earlier sample task/concept file was removed from this folder as part of a cleanup pass; the remaining samples reflect the current, representative set.
