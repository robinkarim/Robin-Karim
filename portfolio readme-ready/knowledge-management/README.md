# Knowledge Management Writing Samples

Samples from IT knowledge base and self-service content work, built on Knowledge-Centered Service (KCS) practices — written so a support team or end user can solve their own problem without escalating it.

## What's in here

- **Knowledge base articles** — sourced from SME and stakeholder interviews, structured for fast scanning under time pressure
- **Self-service content** — troubleshooting and how-to content aimed at reducing repeat tickets
- **Workflow capture documentation** — process knowledge pulled directly from the people doing the work, formatted for reuse across a team rather than living in one person's head

## Background

This work comes from an IT knowledge management engagement in healthcare/insurance, where I conducted SME and stakeholder interviews to build knowledge articles and ran QA review cycles to improve self-service accuracy, and from a multi-year student information system migration where knowledge capture supported 15–20 concurrent workstreams. Client-identifying details have been redacted or generalized.

If you'd like more context on the audit and remediation work behind these samples, I'm happy to walk through it.
