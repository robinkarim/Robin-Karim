# System Implementation Writing Samples

Samples from large-scale system implementation and migration efforts, where the documentation has to keep pace with a platform that's changing underneath it.

## What's in here

- **Implementation guides** — step-by-step rollout documentation for a new platform replacing a legacy system
- **Migration documentation** — content mapping old-system behavior to new-system behavior, written for the teams doing the cutover
- **User guides and runbooks** — end-user and operations content covering day-to-day use of the newly implemented system, including cloud infrastructure runbooks

## Background

This work draws primarily from a four-year student information system migration (Chancery to a new enterprise platform) where I managed integration, implementation, and migration documentation across 15–20 concurrent workstreams, and from cloud infrastructure documentation covering AWS, Kubernetes, and related tooling. Client-identifying details have been redacted or generalized.

If you're evaluating this for a migration-heavy role, let me know and I can point you to the cutover-specific content first.
