# Government and State Policy Writing Samples

Samples from federal and state government engagements, where accuracy, formatting compliance, and audience clarity carry extra weight because the material supports official processes.

## What's in here

- **Federal technical documentation** — supply and reference manuals produced and copy-edited to federal formatting standards, including formatting for e-reader distribution
- **State policy and compliance content** — process and policy documentation prepared for state agency review, written to hold up under audit and public-facing scrutiny
- **Requirements and determination records** — supporting documentation showing how requirements were gathered and validated before final publication

## Background

This work spans a federal engagement producing and editing U.S. Navy supply manuals (handled in accordance with federal material-handling standards) and documentation prepared for Maryland state agency processes. Client-identifying details have been redacted or generalized; given the sensitivity of government-sector material, some samples represent reconstructed or generalized versions of the original deliverables.

If you need to verify DoD security clearance eligibility or handling history for a specific role, that's covered in my resume rather than in this folder.
